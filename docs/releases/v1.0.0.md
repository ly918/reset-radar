# Reset Radar v1.0.0

首个公开版本：在 macOS 菜单栏关注下一次 Codex Reset，查看 AI 概率估计、社区历史与最近公开帖子。

## 下载与安装

- **Reset-Radar-1.0.0-macOS-arm64.dmg**：Apple Silicon（M 系列芯片），macOS 14 或以上。
- **Reset-Radar-1.0.0-macOS-arm64.dmg.sha256**：安装包 SHA-256 校验文件。

打开 DMG，将 **Reset Radar.app** 拖入 **Applications**。从应用程序启动，点击菜单栏图标，在设置中填写自己的 AI 服务 URL、Key 和模型。macOS 26 使用原生 Liquid Glass，旧系统使用系统模糊。

本次只提供 macOS Apple Silicon 安装包；没有 Intel、Windows EXE 或 iOS 版本。

## 功能与修复

- 24h / 12h / 48h 概率卡片，12h 居中并以金色突出，菜单栏图标随概率变化。
- 最近公开帖子的 AI 分类与原文证据，支持第三方 Responses / Chat Completions 接口。
- 最近收录的 Reset 时间与近 7 / 14 / 30 天记录次数。
- 金色拟物 RESET 按钮图标、深浅色自适应、本机 Keychain 密钥存储。
- 修复设置页及历史页关闭问题；设置页增加常驻关闭按钮，并适应较小屏幕。支持 ⌘W / Esc。
- 预测过期、钥匙串需要授权、请求等待和评估失败时显示明确状态。
- README 提供实际应用视图截图。

## 使用说明

概率是根据公开信息生成、未经回测校准的 AI 估计，不代表个人账号必然重置。社区历史是随版本提供的固定归档，可能有缺口。网页读取可能受访问限制影响。

应用目前采用 ad-hoc 本地签名，尚未经过 Apple Developer ID 签名和公证。外部下载后首次打开可能需要在“系统设置 → 隐私与安全性”中确认。安装包不包含个人 Key、账号配置或本机分析缓存。
