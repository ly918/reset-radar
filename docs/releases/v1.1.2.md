# Reset Radar v1.1.2 — Quiet Keychain access

Fixed repeated Keychain authorization dialogs during startup and automatic refresh.

- Startup, including `--start-monitoring`, now reads credentials without requesting system UI.
- Legacy login-keychain operations also honor silent mode. Access remains denied when authorization is needed.
- Background AI retries pause after authorization fails. Use **Authorize & assess** or **Test connection** to retry explicitly.
- Successfully saved/read keys are reused only in memory for the current app session.

## Download

- `Reset-Radar-1.1.2-macOS-arm64.dmg`
- `Reset-Radar-1.1.2-macOS-arm64.dmg.sha256`

For Apple Silicon, macOS 14+. Replace the app in Applications. Settings, Keychain items and cached data are retained. The app is ad-hoc signed and not notarized; a new build may still require a one-time manual Keychain authorization. No access controls are removed and no plaintext credential storage is introduced.

## 中文

修复启动与后台自动刷新反复弹出钥匙串授权的问题，兼容传统登录钥匙串。需要授权时暂停后台 AI 读取，由用户点击“授权并评估”或“测试连接”后再请求系统授权。已保存或成功读取的密钥在本次进程中复用，退出后不保留内存副本。

当前版本仍使用临时签名，升级后可能需要手动授权一次；修复不会绕过系统访问权限。
