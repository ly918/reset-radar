# Reset Radar v0.4.0 — macOS Preview

首个公开预览版本：在菜单栏查看未来 12 小时 Reset 概率，结合公开帖子、AI 分析与社区历史记录。

## 下载附件

待发布 Release 时上传：

- `Reset-Radar-0.4.0-macOS-arm64.dmg`
- `Reset-Radar-0.4.0-macOS-arm64.dmg.sha256`

适用 Apple Silicon、macOS 14+；macOS 26 使用 Liquid Glass。打开 DMG，将应用拖入 Applications。当前没有 Intel、Windows 或 iOS 安装包。

## 主要功能

- 24h / 12h / 48h 概率卡片与动态菜单栏图标。
- 最新真实帖子的 AI 分类、原文证据和全局 Reset 概率估计。
- 第三方 API URL + Key + 模型配置。
- 最近收录的 Reset 时间及近 7 / 14 / 30 天次数。
- 金色 RESET 按钮 Logo、原生透明面板、本机密钥管理和可选定时检查。

## 已知限制

预览版尚未 Developer ID 签名或 Apple 公证。概率未经回测校准，不代表个人账号实际重置。历史是固定社区元数据快照，源页面抓取可能失败或遗漏上下文；应用不会自行确认实际到账。

## 发布操作

源码提交后，确认 `main` 的构建和 `./scripts/check.sh` 通过，运行 `./scripts/package-dmg.sh`。在 GitHub Releases 新建 `v0.4.0`，选择对应提交，勾选 Pre-release，并上传上述两个文件。发布成功后更新 README 的“首次 Release 尚待发布”提示。
