# 第三方数据说明

`community-reset-history.json` 是从 codex-reset.com 公开 API 整理的事实元数据快照，仅保留事件 ID、公告时间、社区类型、出处及核验状态。没有收录原帖全文、站点摘要、图表、软件或第三方预测值。

- 来源：[公开 API](https://codex-reset.com/api/timeline)、[时间线](https://codex-reset.com/timeline)、[使用条款](https://codex-reset.com/terms)。
- 部分时间戳与 [codex-reset.today](https://codex-reset.today/) 交叉比较；共同引用同一原帖不等于独立事实核验。
- 项目的 MIT 许可仅覆盖本项目有权授权的代码、文档和原创素材，不授予第三方网站、原帖或商标的权利，也不声称上游数据整体采用 MIT。
- 公告时间不等于实际生效时间，社区标签不等于独立核验。归档可能遗漏，不用于声明个人账户额度。

`reset-events.json` 是独立核验事件集，目前为空。合成测试材料不作为事实来源。重新导入和再使用上游数据时请保留出处、核验状态与当前适用的来源条件。
